```

python scripts/p09_t01_1_mechanics.py                          # needs PoB, refuses dirty or unpinned
```

the call list is in `seed/manifest.json`. No token is stored.

## Adverse cases

- Generator: an unknown gap id in a field, an invalid DataGap, a share code
  that does not decode to the stored XML, and a cited mechanic id missing from
  the extract each stop the run.
- Extract: an unpinned or dirty PoB checkout is refused.
- Tests: null value without a gap, unresolved basis with a value, a gate
  without numeric/event definition, a reference slot filled, the character
  name outside the seed manifest, and generator drift each fail.
- Untested: nothing runs an evaluator against these scenarios; none exists.
