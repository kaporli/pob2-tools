## Adverse cases

- The `FakeWorker` raises `FakeWorkerError` for any Lua snippet it has no canned
  answer for, so a change to the production snippets surfaces as a failure
  rather than a wrong default.
- The A-B-A checks require B to differ from A before comparing A to A; otherwise
  the check would pass vacuously.
- `test_a_dropped_affix_does_not_reach_the_calculation` compares conversion with
  and without the crafted affix and asserts the outputs are byte-identical,
  which rules out "the affix was emitted somewhere else in the string".
- Malformed build input: exercised, and it is *accepted* (P00-OBS-01).
- **Untested**: forced worker termination and native crash recovery; a wedged
  evaluation hitting a timeout (there is no timeout to hit); concurrent engines.
  Those belong to P02-T01 and need the adapter that does not exist yet.

## Deviations and unresolved questions

1. **F05 is partly source-level.** Cache identity is executed against the real
   `load_phase`/`save_phase`. The league default, the point-budget formulas and
   the literal result caps live inside phase functions that cannot run without
   PoB and a full harvest, so those three are pinned by asserting on the module
   source. The repaired expectations are expressed the same way, so the xfails
   still flip when the literals go.
2. **The LuaJIT probe is not the PoB engine.** It stubs `escapeGGGString` with
   identity and `dkjson` with a never-called double, and asserts only on the
   presence or absence of mod lines, which those stubs cannot affect. The engine
   test then confirms the same output with PoB's real globals. Calling it out
   because it is an unusual evidence route.
3. **Four new observations (P00-OBS-01..04) are not research findings.** They
   need a reviewer decision on which project owns them. P00-OBS-02 in particular
   may deserve promotion to a numbered research finding.
4. **P00-OBS-03 is deliberately not given a repaired expectation.** Whether
   deallocating a passive should prune orphaned path nodes is a game rule, and
   inventing one here would be exactly the guessed constant the specification
   forbids.
5. **No revision to the default engine timeouts is proposed.** The measured
   operations are far below the 120 s / 30 s defaults, but no P07-scale
   evaluation exists to measure, so the defaults stand.
6. The `Windows fatal exception: code 0xe24c4a02` banner printed once per engine
   boot is LuaJIT's internal SEH unwinding, caught internally. `faulthandler`
   was left enabled so that a genuine native crash stays visible.
