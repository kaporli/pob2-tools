## Adverse cases

- Dirty or unpinned checkout: both scripts refuse; the engine test skips.
- Document edits fail loudly on a group or gem that is absent or already disabled.
- A rule citing missing evidence, or a non-resolved rule without an open gap, fails the unit tests.
- Untested: Python 3.10 (not rerun for this change); the full engine suite (only targeted engine tests were run, per the shared memory rule).
