Baseline inventory regeneration is a short script embedded in the task history;
the produced artifact `docs/evidence/P00/baseline/legacy-runs.json` carries the
hashes, so it can be verified without rerunning anything:

```
python - <<'PY'
import hashlib, json, pathlib
inv = json.loads(pathlib.Path("docs/evidence/P00/baseline/legacy-runs.json").read_text())
root = pathlib.Path(inv["source_directory"])
bad = [f["name"] for r in inv["runs"] for f in r["files"]
       if hashlib.sha256((root / r["run"] / f["name"]).read_bytes()).hexdigest() != f["sha256"]]
print("mismatches:", bad)
PY
```

No command here requires a credential. None prints one.
