## Findings

### R1 — P1: Pool construction does not enforce its profile's input scope

Location: `pob2-optimizer/pob2opt/market/pools.py:179–190`.
Only catalog-versus-profile equality is checked. Item `catalog_hash` and
listing `realm`/`league_id` are ignored. An item explicitly belonging to a
different catalog is offered in both ring slots under the current catalog;
a listing from `not-poe2` / `not-Invented` is offered under the fixture's
`poe2` / `Invented` profile. A mixed corpus is a supported storage situation,
so an otherwise valid record is not necessarily usable in this pool.

Required repair: enforce item catalog and listing realm/league scope before
deduplication, enabling matching or sampling. Refuse or report excluded inputs
with reasons. If cross-league theoretical item use is desired, make that a
separate explicit mode which cannot inherit foreign listing availability.
Acceptance: mixed-catalog and mixed-league inputs never create apparently
eligible current-profile candidates; matching-scope controls still work.

### R2 — P2: Duplicate item resolution depends on iteration order

Location: `pob2-optimizer/pob2opt/market/pools.py:185–187`.
`setdefault(item.item_hash, item)` keeps the first record without resolving
differences in readiness. `item_hash` excludes the item-level `parse_status`.
For two records with the same hash, one partial and one complete, ordering
partial first gives no candidates; reversing the same input multiset offers
the item in both ring slots. This changes the search space and pool identity
according to repository iteration order, despite deterministic-pool claims.

Required repair: define a deterministic, conservative policy for duplicate
normalized identities after scope filtering. Either resolve using documented
validity/evidence precedence or report a conflict; do not silently choose the
first. Acceptance: permutations yield the same pool and diagnostics, including
complete/partial duplicates and old/current-catalog variants. A partial record
must not be promoted merely because another source claims completeness.
