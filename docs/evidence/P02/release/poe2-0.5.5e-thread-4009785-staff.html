0.5.5e Patch Notes

0.5.5e Patch Notes


  • Added a new Texture Quality setting for machines with low VRAM.
  • Fixed a bug where killing some specific bosses would prevent Ritual encounters from starting.
  • Fixed a bug where the Tomb of the Fallen Knight could not be accessed.
  • Fixed an issue where some areas were particularly slow to load.
  • Fixed a bug where decorations from The Sovereign Hideout were missing 2D art.
